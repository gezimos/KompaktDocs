# Updates

Your apps, accounts and settings stay. No wipe is needed.

:::warning[From 1.1 to 1.2: update manually]
- Update to 1.2 manually, with `adb reboot sideload` below. Over the air does
  not work for this update.
- From 1.2 on, updates come over the air.
:::

## Update manually

The same update package as the first install. Take the one for your phone and
edition:

| | GApps | Vanilla |
|---|---|---|
| Global | [`KompaktOS-1.2-Global-GApps.zip`](https://github.com/gezimos/KompaktOS/releases/download/v1.2/KompaktOS-1.2-Global-GApps.zip) | [`KompaktOS-1.2-Global-Vanilla.zip`](https://github.com/gezimos/KompaktOS/releases/download/v1.2/KompaktOS-1.2-Global-Vanilla.zip) |
| North American | [`KompaktOS-1.2-USA-GApps.zip`](https://github.com/gezimos/KompaktOS/releases/download/v1.2/KompaktOS-1.2-USA-GApps.zip) | [`KompaktOS-1.2-USA-Vanilla.zip`](https://github.com/gezimos/KompaktOS/releases/download/v1.2/KompaktOS-1.2-USA-Vanilla.zip) |

1. Connect the phone to the computer, with USB debugging on.
2. Restart it into the recovery, ready for the package:

   ```
   adb reboot sideload
   ```

   The recovery opens **Apply from ADB** by itself.
3. On the computer:

   ```
   adb sideload /path/to/KompaktOS-1.2-Global-GApps.zip
   ```

- The computer's counter stops at about 47% and stays there. That is normal.
- The phone has read the whole file by then and installs it from memory. Watch
  the bar on the phone instead.

<Screenshot src="/img/screens/lineage-recovery-sideload.svg" caption="Waiting for adb sideload." />

### While it installs

It checks the package first, then installs it, with a bar and a percentage at
the bottom. It takes about 7 minutes. **Do not interrupt it:** the phone is not
usable until the install finishes.

<Screenshot src="/img/screens/lineage-recovery-installing.svg" caption="Installing, with the bar at the bottom." />

### When it finishes

- After **Step 2/2**, the recovery asks whether to reboot to recovery to
  install more packages. This question means the install worked.
- Choose **No**. The log then shows `Install completed with status 0.`
- Choose **Reboot system now**.

<Screenshot src="/img/screens/lineage-recovery-reboot-prompt.svg" caption="Choose No, then Reboot system now." />

### From the SD card

Without USB, from the recovery's menu:

1. Copy the update package to the SD card.
2. Open the recovery:

   ```
   adb reboot recovery
   ```

3. **Apply update** → **Choose from sdcard1**, and pick the file.

- LineageOS recovery works both by touch and with the buttons: Volume-Up and
  Volume-Down to move, Power to select.
- The install and the end are the same as with `adb sideload`.

## Over the air

From 1.2 on.

1. Settings → System → **System updates** → **Check for updates**. A new
   update shows up under it, named by its date.
2. Tap the update, then **Install**.
3. Tap **OK**. It installs in the background: you can keep using the phone.
4. When it says **Update pending reboot**, tap **Reboot**.

- The phone needs at least 30% battery, or 20% while charging.
- It picks the right package for your phone and edition by itself.

## After an update

- **Apps you installed can feel slower for a day.** An update makes Android
  recompile them, and it does that when the phone is idle and charging,
  usually the first night.
- **Optional: recompile them now.** With the phone charging, on the computer:

  ```
  adb shell pm art dexopt-packages -r bg-dexopt
  ```

  It takes a few minutes; the command returns when it is done.
