# Troubleshooting

## VoLTE or Wi-Fi calling issues

See [Post install](/install/post-install#calls-over-4g-volte).

## Slow, no network in apps, or crashes

You installed without formatting data. Do
[Factory reset / format data](/install/install-kompaktos#2-factory-reset--format-data),
then install the zip package again.

## The install stops with an error

The download may be incomplete. Every release lists the md5 of each file;
compare yours:

```
md5 -q KompaktOS-1.1-Global-GApps.zip                    # macOS
md5sum KompaktOS-1.1-Global-GApps.zip                    # Linux
certutil -hashfile KompaktOS-1.1-Global-GApps.zip MD5    # Windows
```

If it does not match, download the file again.

## "Verify your PIN" after formatting data

Setup asks for the old PIN or pattern, or a new PIN will not set: see
[Erase FRP](/install/erase-frp).

## Messages that are not errors

**`Install completed with status 3. Installation aborted.`** in the recovery.
You left **Apply from ADB** without sending a file. Nothing was installed and
nothing is wrong.

**`No such file or directory`** from `adb sideload` or `fastboot flash`. The
computer cannot find the file: it is not in the folder your terminal is in.
Type the full path to it, or drag the file into the terminal window.
