# Troubleshooting

## Calls over 4G do not work

:::warning[Last resort]

KompaktOS sets up the IMS APN by itself for most carriers. Add PHH IMS only if
calls over 4G still fail after every step in
[Calls over 4G](/install/post-install#calls-over-4g-volte).

:::

<Tabs groupId="phh-ims">
<TabItem value="add" label="Add PHH IMS" default>

1. Settings → **System** → **TrebleDroid Settings** → **IMS features** → tap
   **Create IMS APN**.
2. Restart the phone and try a call.

Still no calls: ask your carrier for their APN settings.

</TabItem>
<TabItem value="delete" label="Delete PHH IMS">

Calls and data stopped after you added it: your carrier already had its own
IMS APN. Remove PHH IMS:

1. On the computer:

   ```
   adb shell
   ```

2. Then:

   ```
   content delete --uri content://telephony/carriers --where "name='PHH IMS'"
   ```

3. Type `exit` and restart the phone.

</TabItem>
</Tabs>

## Slow, no network in apps, or crashes

You installed without formatting data. Do
[Factory reset / format data](/install/install-kompaktos#2-factory-reset--format-data),
then install the zip package again.

## fastboot lists no device

`fastboot devices` prints nothing while the phone is in the bootloader.

- **Try another cable.** A cable can work for adb and still fail in fastboot.
- **On a Mac, allow the accessory.** The bootloader shows up as a new USB device,
  so macOS asks again whether to allow it to connect.
- **On Windows, install Google's USB driver.** Windows has no driver for the
  bootloader, so `fastboot devices` lists nothing even when adb works.
  1. Download the [Google USB Driver](https://developer.android.com/studio/run/win-usb)
     and extract the zip.
  2. With the phone in the bootloader, open **Device Manager**. The phone is
     listed with a warning icon, as **Android** or under **Other devices**.
  3. Right-click it → **Update driver** → **Browse my computer for drivers** →
     pick the extracted `usb_driver` folder → Next.
  4. It installs as **Android Bootloader Interface**. Run `fastboot devices`
     again.

## The install stops with an error

The download may be incomplete. Every release lists the md5 of each file;
compare yours:

```
md5 -q KompaktOS-1.1-Global-GApps.zip                    # macOS
md5sum KompaktOS-1.1-Global-GApps.zip                    # Linux
certutil -hashfile KompaktOS-1.1-Global-GApps.zip MD5    # Windows
```

If it does not match, download the file again.

## "Verify your PIN" after formatting data

Setup asks for the old PIN or pattern, or a new PIN will not set: see
[Erase FRP](/install/erase-frp).

## Messages that are not errors

**`Install completed with status 3. Installation aborted.`** in the recovery.
You left **Apply from ADB** without sending a file. Nothing was installed and
nothing is wrong.

**`No such file or directory`** from `adb sideload` or `fastboot flash`. The
computer cannot find the file: it is not in the folder your terminal is in.
Type the full path to it, or drag the file into the terminal window.
