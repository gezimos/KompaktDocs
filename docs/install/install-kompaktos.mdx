# Install

:::note[Haven't read the Requirements yet? Read them first]

<Link className="button button--primary" to="/prepare/requirements">Requirements</Link>

## Back up first

- **Your data:** copy your photos, files and anything else you want to keep to
  a computer.
- **The whole phone, once:** make a full backup with
  [mtkclient](/prepare/mtkclient). If anything ever goes wrong, it puts the
  phone back as it was.

## Steps

1. Flash recovery (first install only).
2. Factory reset / format data.
3. Install the zip package from the recovery.

## 1. Flash recovery

<Tabs groupId="start">
<TabItem value="bootloader" label="Already in the bootloader">

You just unlocked the bootloader with [Unlocking](/prepare/unlocking) and the
phone has not restarted since.

```
fastboot flash boot /path/to/KompaktOS-Kernel-LineageOS-Recovery-1.0.img
fastboot reboot recovery
```

</TabItem>
<TabItem value="booted" label="Booted in MuditaOS">

The phone is on, with an unlocked bootloader and USB debugging turned on.

```
adb reboot bootloader
fastboot flash boot /path/to/KompaktOS-Kernel-LineageOS-Recovery-1.0.img
fastboot reboot recovery
```

</TabItem>
</Tabs>

- Drag the file onto the terminal window to paste its path, or copy and paste
  the path if your system allows it.
- Only needed once: every update package brings the recovery with it.

## 2. Factory reset / format data

<ScreenshotRow>
  <Screenshot src="/img/screens/lineage-recovery-select-factory-reset.svg" caption="Tap Factory reset." />
  <Screenshot src="/img/screens/lineage-recovery-factory-reset.svg" caption="Then Format data/factory reset." />
  <Screenshot src="/img/screens/lineage-recovery-format-confirm.svg" caption="Confirm with Format data." />
</ScreenshotRow>

1. In the recovery, tap **Factory reset**.
2. Tap **Format data/factory reset**.
3. Tap **Format data** to confirm.

If setup later asks for your old PIN or pattern: see
[Erase FRP](/install/erase-frp).

## 3. Install the zip package

<ScreenshotRow>
  <Screenshot src="/img/screens/lineage-recovery-select-apply.svg" caption="Tap Apply update." />
  <Screenshot src="/img/screens/lineage-recovery-apply.svg" caption="Then Apply from ADB, or the SD card." />
</ScreenshotRow>

1. **Apply update** → **Apply from ADB**.
2. On the computer:

   ```
   adb sideload /path/to/KompaktOS-1.1-Global-GApps.zip
   ```

The computer's counter stops at about 47% and stays there. That is normal: the
phone has read the whole file and installs it from memory. Watch the bar on the
phone instead. It takes about 7 minutes. **Do not interrupt it.**

You can also install from the SD card instead of over USB: see
[Updates](/install/updates#from-the-sd-card).

## 4. Restart

When it finishes, it asks whether to reboot to recovery to install more
packages. Choose **No**, then **Reboot system now**.

<Screenshot src="/img/screens/lineage-recovery-reboot-prompt.svg" caption="Choose No, then Reboot system now." />
