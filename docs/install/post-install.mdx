# Post install

After installing, in this order:

1. [Wait out the first start](#the-first-start).
2. [Choose a launcher](#choose-a-launcher).
3. [Set up calls over 4G](#calls-over-4g-volte), needed to make calls on most
   networks.
4. Optional: [turn on Wi-Fi calling](#wi-fi-calling).
5. GApps edition: [remove the Play Protect popup](#play-protect-popup-gapps).

## The first start

- **The first boot takes several minutes.** The e-ink panel only repaints when
  something changes, so it can look stuck: leave it alone for five minutes.
- **After that, the phone can feel slow for a while.** Android is still
  setting up apps in the background. It is snappy again once that finishes.

:::danger[Do not use a pattern lock]

Pattern locks are broken and can lock you out of the phone. Use a PIN or a
password.

:::

## Calls over 4G (VoLTE)

Where 2G and 3G are switched off, every call goes over 4G. Without it the
phone has signal and mobile data and still cannot make or receive calls. You
set it up once.

1. **Settings** → **System** → **TrebleDroid Settings** → **IMS features** →
   **Install IMS APK for MediaTek R+ vendor**.
2. Open the download from the notification, or from **Files** → Downloads, and
   install it. With Google Play services, tap **Install anyway** at the alert.
3. In the same **IMS features** page, check that **Force the presence of 4G
   Calling setting** is on.
4. Restart the phone.
5. Settings → **Network & internet** → **SIMs** → your SIM → turn on **VoLTE**.

## Wi-Fi calling

Make and receive calls over Wi-Fi where the mobile signal is weak or missing. Set up
[calls over 4G](#calls-over-4g-volte) first.

1. Settings → **Network & internet** → **SIMs** → your SIM → **Wi-Fi
   calling**.
2. Turn on **Use Wi-Fi calling**.
3. **Calling preference**:
   - **Wi-Fi preferred**: calls use Wi-Fi whenever you are connected to it.
   - **Mobile preferred**: calls use Wi-Fi only when there is no mobile
     signal.

- **To test it**, turn on airplane mode, turn Wi-Fi back on, wait a few
  seconds and make a call. With no mobile signal, the call can only go over
  Wi-Fi.
- **Your carrier must offer Wi-Fi calling.** If it does not, nothing changes:
  calls still go over 4G.

## Play Protect popup (GApps)

On the GApps edition Google may show "This device isn't Play Protect
certified", which stops the Play Store and other Google apps. Registering the
phone's device ID once with Google removes it: updates keep it, only a factory
reset undoes it.

<a className="button button--primary button--lg" href="https://www.google.com/android/uncertified/" target="_blank" rel="noopener noreferrer">Register at google.com/android/uncertified</a>

<Screenshot src="/img/screens/play-protect-uncertified.png" caption="This device isn't Play Protect certified." />

### Find the device ID and register it

Do this after setting up the phone. You need [adb](/prepare/unlocking#1-install-adb).

1. Settings → System → Developer options → turn on **Rooted debugging**
   (with **USB debugging** on).
2. Read your device ID. There are two ways: pick a tab, **Google's command**
   or **Any computer**.

<Tabs groupId="device-id">
<TabItem value="google" label="Google's command (macOS, Linux)">

As shown on [google.com/android/uncertified](https://www.google.com/android/uncertified/):

```
adb root
adb shell 'sqlite3 /data/user/$(cmd activity get-current-user)/*/*/gservices.db \
    "select * from main where name = \"android_id\";"'
```

- **It prints `android_id|` and a long number.** The number is your ID.
- **macOS or Linux only.** Windows Command Prompt and PowerShell do not read the
  single quotes.
- **Copy it exactly.** Forums and chat apps often drop the `*`, and then it
  fails with "no such table".

</TabItem>
<TabItem value="kompakt" label="Any computer">

On the computer:

```
adb root
adb shell
```

Then in the phone shell that opens:

```
sqlite3 $(find /data/user/$(cmd activity get-current-user) -mindepth 3 -maxdepth 3 -name gservices.db | head -1) "select value from main where name='android_id';"
exit
```

- **It prints a long number.** That number is your ID.
- **Windows, macOS and Linux work the same way.** The line runs on the phone,
  not on your computer.
- **It has no `*` in it,** so nothing gets lost when it is copied.

</TabItem>
</Tabs>

- **"Permission denied" or "unable to open database":** Rooted debugging is off,
  or `adb root` was not run first.

3. Open [google.com/android/uncertified](https://www.google.com/android/uncertified/),
   sign in with the Google account you use on the phone, and paste the number.
4. Restart the phone.
5. **Only if the popup is still there:** make the phone check again, then
   restart once more. Open a shell on the phone (`adb root`, then `adb shell`)
   and run:

   ```
   am broadcast -a android.server.checkin.CHECKIN
   rm -f /data/data/com.google.android.gms/files/gmscompliance/shared/cache.pb
   rm -rf /data/data/com.android.vending/cache
   exit
   ```

6. Turn **Rooted debugging** off again.

Google Play Protect will still say "not certified". What counts is that the
popup is gone and the Play Store opens and installs apps.
