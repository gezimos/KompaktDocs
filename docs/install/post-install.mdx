# Post install

## The first start

- **The first boot takes several minutes.** The e-ink panel only repaints when
  something changes, so it can look stuck: leave it alone for five minutes.
- **After that, the phone can feel slow for a while.** Android is still
  setting up apps in the background.
- **Once that finishes, it is snappy again.** Nothing to do but wait.

## Choose a launcher

On first boot, the phone asks you to choose your default launcher:

- Choose **inkOS** or **Katapult**.
- **Trebuchet**, LineageOS's own launcher, is not made for e-ink.

  <Screenshot src="/img/screens/launcher-katapult.png" caption="Katapult." />

**inkOS**

- Its swipe-down gesture opens its own notification and toggle window, which
  gets in the way of Android's. Turn it off: inkOS settings → **Gestures** →
  swipe down → **Disabled**.
- To show the status bar: inkOS settings → **Look and feel** → **Enable status
  bar**.

**Katapult**

- To show the status bar: Katapult settings → **Appearance** → turn off **Hide
  status bar**.

## Calls over 4G (VoLTE)

Where 2G and 3G are switched off, every call goes over 4G. Without 4G calling
the phone has signal and mobile data and still cannot make or receive calls.

- 4G calling needs MediaTek's IMS app, which KompaktOS cannot include.
- You set it up once.
- The IMS settings are in **Settings** → **System** → **TrebleDroid Settings** →
  **IMS features**.

<ScreenshotRow>
  <Screenshot src="/img/screens/ims-1-system.png" caption="Settings → System → TrebleDroid Settings." />
  <Screenshot src="/img/screens/ims-2-trebledroid.png" caption="IMS features." />
  <Screenshot src="/img/screens/ims-3-features.png" caption="Install the IMS APK, then force the 4G Calling setting." />
</ScreenshotRow>

1. In **IMS features**, tap **Install IMS APK for
   MediaTek R+ vendor**.
2. When the download finishes, open it from the notification, or find it in
   **Files** under Downloads, and tap it to install. If you use Google Play
   services, you get an alert about it: tap **Install anyway**.
3. Restart the phone.
4. In **IMS features**, turn on **Force the presence of
   4G Calling setting**. Some SIMs hide the VoLTE switch otherwise.
5. Settings → **Network & internet** → **SIMs** → your SIM, and turn on
   **VoLTE**.
6. Check it registered: Kompakt app → **Settings** → **Diagnostics** → **Calls
   over 4G**. You want **IMS app** Installed, **4G Calling** On and
   **Registered** Yes. Registering can take a minute after the restart.

### If Registered stays No

Check with your carrier for the correct APN settings, including the `ims` APN,
and add them in Settings → **Network & internet** → **SIMs** → your SIM →
**Access Point Names**. Then restart the phone.

## Play Protect popup (GApps)

On the GApps edition Google may trigger Play Protect, which stops you from
using the Play Store and other Google apps.

<Screenshot src="/img/screens/play-protect-uncertified.png" caption="This device isn't Play Protect certified." />

To avoid this, I recommend doing the following after you have finished setting
up your device. You only need to do it once: updates keep it, only a factory
reset undoes it.

You need [adb](/prepare/unlocking#1-install-adb).

1. Settings → System → Developer options → turn on **Rooted debugging**
   (with **USB debugging** on).
2. Read your device ID:

   ```
   adb root
   adb shell 'sqlite3 /data/data/com.google.android.gsf/databases/gservices.db "select * from main where name = \"android_id\";"'
   ```

   It prints `android_id|` and a long number. That number is your ID.
3. Open [google.com/android/uncertified](https://www.google.com/android/uncertified/),
   sign in with the Google account you use on the phone, and paste the number.
4. Make the phone pick it up:

   ```
   adb shell am broadcast -a android.server.checkin.CHECKIN
   adb shell rm -f /data/data/com.google.android.gms/files/gmscompliance/shared/cache.pb
   adb shell 'rm -rf /data/data/com.android.vending/cache/*'
   ```

5. Restart the phone, then turn **Rooted debugging** off again.

Settings may still say "not certified". What counts is that the popup is gone
and the Play Store opens and installs apps.
