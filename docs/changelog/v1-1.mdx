# KompaktOS 1.1

3 October 2026.

## Calls

- **Wi-Fi calling works.** Tested on Telia LT, T-Mobile and AT&T. Your carrier
  must offer it: see [Wi-Fi calling](/install/post-install#wi-fi-calling).
- **Calls over 4G work on more carriers out of the box.** About 640 more
  carriers get the settings for it, so **Create IMS APN** is only needed for
  the rest.
- **4G calls work straight after setup.** You no longer have to turn them off
  and on again.
- **Create IMS APN** now confirms with a message.
- **Airplane mode keeps the mobile radio off.**
