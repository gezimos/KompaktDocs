# Changelog

Download every release from
[GitHub Releases](https://github.com/gezimos/KompaktOS/releases). Install an
update [from the recovery](/install/updates), or let the Updater offer it.

## 1.1

3 October 2026.

### Calls

- **Wi-Fi calling works.** Tested on Telia LT, T-Mobile and AT&T. Your carrier
  must offer it: see [Wi-Fi calling](/install/post-install#wi-fi-calling).
- **Calls over 4G work on more carriers out of the box.** The `ims` access
  point name is now included for about 640 more carriers, so **Create IMS APN**
  is only needed for the rest.
- **VoLTE works straight after setup.** You no longer have to turn it off and
  on again.
- **Create IMS APN** now confirms with a message.
- **Airplane mode keeps the mobile radio off.**
