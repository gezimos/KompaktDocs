# Requirements

- **A computer with adb and fastboot:** see
  [Install ADB](/prepare/unlocking#1-install-adb).
- **An unlocked bootloader:** see [Unlocking](/prepare/unlocking).
- **A backup** of anything you want to keep: installing over MuditaOS or another
  system erases the phone.
- **The files for your phone and edition:** see
  [Install](/install/install-kompaktos#what-you-need).
- **No downgrade needed:** whatever MuditaOS version you are on, you install
  KompaktOS directly.

**Relocking is only possible with MuditaOS-K installed. Do not try to relock
with KompaktOS.**
